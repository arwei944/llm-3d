说明
模型：2 层 · d=32 · 4 头 · MLP 64 · 上下文 16 · 词表 12，约 2.8k 参数，浏览器内真实训练 900 步（下一字符准确率 8.3% → 82.6%）。

推理：Embedding → RoPE → 每层 RMSNorm / QKV / 多头因果注意力 / 残差 / MLP → 输出头 → 温度 softmax → Top-p 采样 → 自回归追加。

训练：采样批次 → 前向 → 交叉熵 → 反向传播（梯度柱 = 真实 ‖∂L/∂θ‖）→ 梯度裁剪 → AdamW 更新（立方体 = 真实权重）→ loss 曲线下降。

采样实验室：温度 / Top-K / Top-P 实时驱动真实 forward，看概率分布与采样结果怎么变。

注意力探针：选层、选头、选查询位置，逐格看真实注意力概率与分工。

上下文与缓存：拖动 T，看因果掩码三角与真实 K/V 缓存墙，O(T²) 连接 vs O(T) 缓存。

科普图谱：十个维度横向扩展（分词 / 语义空间 / 缩放定律 / 幻觉 / RLHF / RAG / 思维链 / 多模态 / 推理成本 / 评测）。

新增模块只需调用 LLMEngine.register({...})，引擎自动生成导航、参数面板、相机行与主循环钩子。

「真实运算示例」面板里的数字由浏览器实时计算，并与 tools/trace.js 在 Node 端独立算出的参考值逐项比对。
